## FAQ（掲載用）

### Q. 進捗はバックアップできますか？
A. 学習データは端末ブラウザの localStorage に保存されます。設定パネルの「進捗をエクスポート／インポート」で JSON バックアップできます。機種変更・キャッシュ削除・別ブラウザでは消えることがあるので、機種変更前に必ずエクスポートしてください。

### Q. 返金できますか？
A. デジタルコンテンツのため、原則として購入後の返金はできません。ZIP が破損している、説明と明らかに異なる等の場合は、購入した BOOTH / DLsite のポリシーに沿ってご連絡ください。購入前に対応環境（特に Android Chrome 推奨・iOS 非保証）をご確認ください。

### Q. iPhone / iPad で使えますか？
A. 一部機能が動くことはありますが、iOS Safari ではホーム画面追加・音声再生・マイク・保存・オフラインなどに制限があります。**主対応は Android Chrome** です。iOS での快適利用は保証しません。

### Q. オフラインで音声は全部聞けますか？
A. Service Worker により、一度取得したファイルはキャッシュされオフラインでも使えるようになります。HTML/主要データはプリキャッシュされますが、**MP3 は再生時に都度キャッシュ**されます。オフライン前に学習・復習で音声を一度通しておくと安心です。未取得の音声はオフラインでは再生できないことがあります（ブラウザ読み上げフォールバックは環境依存）。

### Q. インターネットは不要ですか？
A. アプリ自体に必須の学習サーバーはありません。ローカル起動後、必要なファイルを取得済みならオフライン学習が可能です。マイクの音声認識（任意）は Chrome 等でネットが必要な場合があります。

### Q. インストール方法がわかりません
A. README の手順どおり、解凍 → ローカル HTTP サーバ起動 → Chrome でアクセス → Android なら「ホーム画面に追加」です。`file://` で HTML を直接開く方式は動作が不安定なため推奨しません。

### Q. 商用利用・教室での利用は？
A. ライセンスは**個人の学習利用**が基本です。再配布や組織での一括導入、教材転載は利用規約で禁止しています。必要な場合は販売ページからご相談ください。

### Q. 英語の答えは絶対正しいですか？
A. 学習上の模範例です。別解や場面による言い換えがあります。AI 支援生成を含み、編集していますが、ネイティブ監修の網羅や試験との完全一致は保証しません。

### Q. サブスクですか？アップデートは？
A. v1 は **ZIP 買い切り**です。内容追加はバージョンアップ ZIP の再配布などで行う想定で、月額課金ではありません（将来形態が変わる場合は商品ページで告知）。
