# サポート返信テンプレ（v1）

販売: BOOTH / DLsite ZIP 買い切り想定。短く・責めない・手順優先。

---

## 起動できない

```
ご連絡ありがとうございます。瞬間英作 サポートです。

ブラウザでフォルダを直接開くと動きません。次を試してください。

1. 展開したフォルダでコマンドを開き:
   python -m http.server 8765
2. Chrome で http://localhost:8765/ を開く

Python が入っていない場合は python.org からインストールし、
「Add to PATH」にチェックを入れてください。

それでもダメな場合: OS・ブラウザ名・画面の様子（真っ白/エラー文）を教えてください。
```

---

## 進捗が消えた

```
進捗は端末のブラウザ内（localStorage）にのみ保存されます。
キャッシュ削除・別ブラウザ・機種変更で消えることがあります。

設定 →「進捗をエクスポート」で JSON を保存していれば、
「進捗をインポート」で戻せます。

今後は機種変更の前に必ずエクスポートをお願いします。
バックアップが無い場合、残念ながらこちらから復元はできません。
```

---

## iOS で動かない / マイク不可

```
主対応環境は Android の Chrome です。
iOS Safari では音声認識・ホーム画面追加・音声の一部に制限があります。

学習・自己採点・一覧・復習の多くは使えますが、
マイク（発音確認・シャドウイング）は端末・OS によって動きません。

可能であれば Android Chrome でのご利用をおすすめします。
```

---

## 音声が出ない

```
1. 端末の消音・音量を確認
2. 別の例文の 🔊 をタップ
3. 一度オンラインで開き、音声を再生してキャッシュを作る
4. 設定の音声速度を 0.95 前後に戻す

一部の新しい例文はブラウザ読み上げにフォールバックします。
```
