プライバシーポリシー

瞬間英作（Shunkan Eisaku）　最終更新: 2026年7月17日

本アプリはバックエンドサーバーを持たない静的 PWAです。 学習進捗は原則としてご利用端末内のみに保存され、提供者のサーバーへ送信されません。

1. 事業者について

本サービス「瞬間英作」は個人により開発・販売されています。連絡先は購入した販売ページ（BOOTH / DLsite 等）またはパッケージ同梱の案内に記載します。

2. 収集する情報

2.1 端末内のみ（提供者へ送信しない）

以下はブラウザの localStorage 等に保存され、アプリの学習機能のために使用されます。

  • 学習進捗（問題ごとの自己採点結果、次回出題予定、連続正解など）
  • 設定（レベル／シーン、音声速度、マイク使用の有無、復習オプションなど）
  • オンボーディング表示済みフラグ等の UI 状態

これらのデータは、提供者が運営するサーバーには送信されません（本アプリに専用バックエンドはありません）。

2.2 マイク・音声認識（任意）

  • 発音確認・シャドウイングのためにマイク入力を利用できます。設定から無効化できます。
  • 音声認識にはブラウザの Web Speech Recognition API を使用します。
  • Google Chrome 等では、音声が端末外（クラウド）の認識サービスへ送られる場合があります。これはブラウザ／OS の実装に依存し、本アプリ提供者がその音声データを受領・保管するものではありません。
  • マイクをオフにすれば、当該処理は行われません。

2.3 ネットワーク通信

  • 初回表示や更新時に、HTML / JS / CSS / JSON / 音声 MP3 等の静的ファイルを取得します。
  • Service Worker は network-first（オンライン時は最新を取得し、失敗時のみキャッシュ）で動作します。一度取得した音声などは端末キャッシュに残ることがあります。
  • ZIP をローカル HTTP サーバーで開く場合、通信先は主にご自身の端末／LAN 内です。
  • 外部ホスティング（GitHub Pages 等）で配信する場合、当該ホストのアクセスログ方針が別途適用されます。本アプリ自体はアクセス解析タグを必須としては埋め込みません（将来変更する場合は本ポリシーを更新します）。

2.4 販売・決済

BOOTH・DLsite 等での購入・決済に関する個人情報は、各プラットフォームのプライバシーポリシーに従い取り扱われます。提供者はプラットフォームが提供する範囲の注文情報を知り得る場合がありますが、本アプリの学習データとは別です。

3. 利用目的

  • 学習進捗の表示・SRS（間隔反復）による出題制御
  • 設定の保持と UX の維持
  • （任意）発音確認のための音声認識
  • アプリ本体および学習コンテンツの配信・キャッシュ

4. 第三者提供

提供者は、学習進捗データを第三者に販売・提供しません。ただし、以下は例外または利用者の環境に依存する処理です。

  • 法令に基づく開示が必要な場合
  • ブラウザの音声認識機能がクラウドへ音声を送る場合（2.2 参照）
  • 販売プラットフォーム・決済事業者による取引処理

5. データの保管期間・削除

  • localStorage 上のデータは、利用者がブラウザデータ削除・アプリ内リセット・端末初期化等を行うまで端末に残ります。
  • 学習データの削除は、アプリ内のリセット操作、またはブラウザのサイトデータ削除により行えます。
  • エクスポート機能がある場合、出力ファイルの保管は利用者の責任です。

6. セキュリティ

本サービスは静的ファイルと端末内保存が中心です。端末の紛失・共用・マルウェア等によるデータ漏洩リスクは、利用者側の端末管理に依存します。共用端末ではブラウザデータの扱いにご注意ください。

7. お子様の利用

本サービスは一般向けの英語学習ツールです。保護者の判断と監督のもとでご利用ください。マイク利用時は特にご注意ください。

8. ポリシーの変更

機能追加（例: クラウド同期、外部解析）に伴い本ポリシーを改定することがあります。重要な変更は、アプリ内または配布物にて告知します。

9. お問い合わせ

プライバシーに関するお問い合わせは、購入した販売ページの連絡手段、またはパッケージ同梱の案内までお願いいたします。
