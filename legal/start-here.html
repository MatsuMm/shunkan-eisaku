瞬間英作 v1.0.0

ブラウザで動く英語トレーニング（PWA）です。Android Chrome からホーム画面に追加して使えます。

3ステップで開始（Windows）

  1. このフォルダを好きな場所に置く
  2. フォルダでコマンドを開き、次を実行:
python -m http.server 8765
  1. Chrome で http://localhost:8765/ を開く

注意: HTML をダブルクリックで開くと動きません（セキュリティ制限）。必ず HTTP サーバ経由で。

Android（同じ Wi‑Fi）

  1. PC: python -m http.server 8765 --bind 0.0.0.0
  2. PC の IPv4 を確認（ipconfig）
  3. スマホ Chrome で http://<PCのIP>:8765/
  4. メニュー → ホーム画面に追加

最初にやること

  1. Lv1 の「学習」で声に出す
  2. 答えの前に「口に出した」をチェック
  3. ◯△× で自己採点
  4. 設定から進捗をエクスポート（機種変更対策）

重要

項目内容
進捗端末ブラウザ内のみ。消えたらインポートで復元
音声同梱 MP3 優先。無い場合はブラウザ読み上げ
マイク任意。Chrome では認識がクラウド経由の場合あり
対応Android Chrome 推奨 / iOS は制限あり

困ったとき

  • 読み込み失敗 → 再読み込み。一度オンラインで開く
  • 進捗消失 → 設定のインポート（事前エクスポートが必要）
  • 問い合わせ → 購入した販売ページのメッセージ
