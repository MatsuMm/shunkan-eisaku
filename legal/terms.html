利用規約

瞬間英作（Shunkan Eisaku）　最終更新: 2026年7月17日

本アプリ（以下「本サービス」）は、個人が販売する学習用 PWA（Progressive Web App）です。 ご利用前に本規約をよくお読みください。ダウンロード・インストール・利用開始をもって本規約に同意したものとみなします。

第1条（適用）

本規約は、本サービスの提供条件および利用者と提供者との間の権利義務関係を定めるものです。BOOTH・DLsite 等の販売プラットフォーム経由で取得した場合も、本規約が適用されます（各プラットフォームの規約と矛盾する場合、プラットフォーム規約が優先されることがあります）。

第2条（本サービスの内容）

本サービスは、日本語から英語への瞬間英作文練習を中心としたオフライン対応の学習用静的 Web アプリです。学習モード、一覧、復習プレイリスト、聞き取り、文法、会話、読解、語彙などの機能を含みます。機能内容はバージョンにより変更されることがあります。

第3条（販売形態・ライセンス）

  1. 現行（v1）の販売形態は、BOOTH / DLsite 等での ZIP パッケージ一式の買い切りです。サブスクリプションではありません。
  2. 購入者には、本サービス一式を個人の学習目的で利用する非独占的・譲渡不可のライセンスが付与されます。
  3. 本サービスはオープンソース・ソフトウェアではありません。再配布・再販売・公開リポジトリへのアップロード・ミラー配布は禁止します。
  4. 同一世帯内での個人利用は許容しますが、社内・教室・スクール等での組織的な複数端末への複製配布や、教材としての無断商用転用は禁止します（別途許諾が必要な場合は提供者へご連絡ください）。

第4条（禁止事項）

利用者は、以下の行為をしてはなりません。

  • 本サービス（プログラム、フレーズデータ、音声 MP3、アイコン、文章等）の全部または一部の無断複製・再配布・再販売・レンタル・貸与
  • 逆コンパイル・改変しての二次配布、または本サービスの一部を抜き出して他製品へ組み込む行為
  • フレーズ・解説・音声を抜き出して、自作教材・商用コース・公開サイト等へ転載する行為
  • 本サービスの内容を AI 学習データ等として大規模に抽出・公開する行為
  • 法令または公序良俗に反する利用
  • 本サービスまたは第三者の権利・信用を損なう行為

第5条（コンテンツについて）

  1. フレーズ・解説・会話台本・読解文等は、AI 支援による生成を含み、編集方針に基づき選定・調整したものです。ネイティブチェックの網羅や公式試験との完全一致を保証するものではありません。
  2. 英語表現には別解・地域差・文脈差があります。本サービスの模範解答は学習上の一例であり、唯一の正解を断定するものではありません。
  3. 学習効果・試験合格・業務成果等について、提供者は保証しません。

第6条（音声・マイク機能）

  1. 英語音声は、主に事前生成された MP3（Edge TTS 等）を同梱・配信しています。欠落時はブラウザの読み上げ（Web Speech API）にフォールバックする場合があります。
  2. マイクによる発音確認・シャドウイングは任意機能です。Chrome 等では Web Speech Recognition がクラウド処理を伴う場合があります。設定からオフにできます。
  3. 音声認識の精度・可用性は端末・OS・ブラウザ・ネットワークに依存し、保証しません。

第7条（データ・進捗の保存）

  1. 学習進捗・設定は原則として利用者端末の localStorage のみに保存されます。提供者のサーバーへ学習データを送信する仕組みはありません（バックエンドなし）。
  2. ブラウザデータの削除、キャッシュクリア、別ブラウザ／別端末の利用、OS 再インストール等により進捗が失われることがあります。
  3. エクスポート／インポート機能が提供されている場合は、機種変更前のバックアップに利用してください。機能追加前のバージョンでは手動バックアップができない場合があります。

第8条（対応環境）

  1. 主対応: Android 上の Google Chrome での利用（ホーム画面追加による PWA 利用を推奨）。
  2. iOS Safari では PWA・音声・マイク・ホーム画面追加・オフライン動作等に制限がある場合があります。完全な動作は保証しません。
  3. デスクトップブラウザでも動作し得ますが、サポートの優先度は Android Chrome とします。

第9条（知的財産権）

本サービスに関する著作権その他の知的財産権は、提供者または正当な権利者に帰属します。購入は所有権の譲渡ではなく、第3条の範囲での利用許諾です。

第10条（免責）

  1. 本サービスは「現状有姿（AS IS）」で提供されます。
  2. 提供者は、動作の中断・不具合・データ消失・端末への影響・第三者サービス（ブラウザ音声認識等）の変更に起因する損害について、法令上許容される範囲で責任を負いません。
  3. 販売プラットフォーム上の決済・ダウンロード障害については、各プラットフォームの規定に従ってください。

第11条（返品・返金）

デジタルコンテンツの性質上、原則として購入後の返品・返金には応じられません。ただし、ファイル破損・明らかに動作しない等の不具合が購入者側の環境以外に起因すると認められる場合、販売プラットフォームのポリシーおよび提供者の判断により対応することがあります。購入前に対応環境とデモ／説明文をよくご確認ください。

第12条（規約の変更）

提供者は、必要に応じて本規約を変更できます。変更後の規約は、本サービス内または配布パッケージ内に掲載した時点から効力を生じます。重要な変更がある場合は、可能な範囲で告知します。

第13条（準拠法・管轄）

本規約は日本法を準拠法とします。本サービスに関して紛争が生じた場合、提供者の所在地を管轄する裁判所を第一審の専属的合意管轄裁判所とします。

第14条（お問い合わせ）

本規約に関するお問い合わせは、購入した販売ページ（BOOTH / DLsite 等）に記載の連絡手段、またはパッケージ同梱の案内に従ってください。
